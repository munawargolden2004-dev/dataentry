# Data Dash

A complete travel agency management system for managing visa applications, flight bookings, hotels, Umrah packages, and travel insurance.

## What It Does

- **Visa Management** — Track visa applications, statuses, documents, and approvals
- **Ticketing** — Book and manage flight tickets, with reissue and refund handling
- **Hotels** — Manage hotel reservations and bookings
- **Umrah Packages** — Full Umrah pilgrimage package management with pricing
- **Insurance** — Travel insurance booking and tracking
- **Analytics** — Dashboard with revenue, statistics, and booking charts
- **Admin Dashboard** — Manage employees, view all bookings, track payments
- **Employee Management** — Create staff accounts, assign roles
- **User Roles** — Admin and employee access levels with data isolation
- **Search & Filter** — Find bookings by country, status, date, or name
- **Pagination** — Browse 10 records per page
- **Content Protection** — Block screenshots, downloads, copying, and printing
